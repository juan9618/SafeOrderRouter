# SafeOrderRouter

Proyecto académico simulado para aplicar herramientas de calidad de software.

SafeOrderRouter representa un componente simplificado de procesamiento y
enrutamiento de órdenes. El proyecto no utiliza código real ni datos
financieros reales.

## Objetivos

- Validar órdenes.
- Aplicar controles de riesgo.
- Simular el envío de órdenes a un mercado.
- Aplicar pruebas automatizadas con JUnit 5.
- Analizar calidad de código mediante SonarQube Cloud.

## Herramientas

- Java 21
- Maven
- JUnit 5
- JaCoCo
- SonarQube Cloud
- GitHub Actions
